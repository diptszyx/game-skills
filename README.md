# game-skills
Bộ skill cho Claude Code để làm game (Unity, solo + AI): quy trình, bài học và cổng kiểm đã rút từ game-1/2/3 và `indie-game`.
- `skills/<tên>/SKILL.md`: từng skill (viết theo tài liệu chính thức, xem `docs/SKILL_AUTHORING_OFFICIAL.md`).
- `docs/PLAN.md`: trạng thái và kế hoạch (đọc đầu tiên). `docs/SKILL_INVENTORY.md`: 182 bài học nguồn.
- `briefs/`: brief giao Codex cho việc về skill.
Cài: `ln -s <đường dẫn tuyệt đối>/skills/<tên> ~/.claude/skills/<tên>`.
